# PerpsCopier documentation

[PerpsCopier](https://perpscopier.com/) is a Windows desktop trade copier for **Vest Markets** perps (including **Vest Capital** accounts), **Tradovate** futures and **Rithmic** futures (including TradeSea firms). You trade one account, the **leader**. Your other accounts, the **followers**, copy it, each at its own size.

PerpsCopier runs on **Windows 10 and 11**. Mac is coming soon.

> **Important:** copying happens inside the app, on your computer. Keep PerpsCopier running while you trade. Use an always-on PC or a Windows VPS.
